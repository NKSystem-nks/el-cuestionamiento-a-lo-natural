- `assets/favicon.png`: icono tomado del logotipo original.

### Comprobaciones importantes

- Se conservan el ensayo, los aforismos, la dedicatoria y fecha de publicación del ZIP fuente.
- La foto y el video de la dedicatoria son públicos para todo visitante. **Confirma que deseas compartirlos antes de activar GitHub Pages.**
- Las 30 fotografías siguen siendo ampliables. El video requiere que la persona pulse reproducir.
- La interfaz no utiliza dependencias externas, analíticas ni bases de datos. La marca de tramo leído se guarda exclusivamente en el navegador del visitante (almacenamiento local).
- Evitar agregar fuentes comerciales sin confirmar licencia de incrustación. El sitio emplea alternativas del sistema cuando no existe Bahnschrift.

## Publicación gratuita con GitHub Pages

1. Entra a https://github.com y crea/inicia sesión en tu cuenta.
2. Crea un repositorio **público** (por ejemplo, `el-cuestionamiento-a-lo-natural`).
3. En la raíz del repositorio, sube **el contenido de este ZIP descomprimido**: `index.html`, carpeta `assets` y este archivo de instrucciones. El `index.html` debe quedar en la raíz, no dentro de otra carpeta.
4. En el repositorio, entra a **Settings → Pages → Build and deployment**, elige `Deploy from a branch`, rama `main`, carpeta `/(root)` y guarda.
5. Cuando GitHub indique la URL, abre `https://TU_USUARIO.github.io/el-cuestionamiento-a-lo-natural/` desde el celular.
6. Prueba abrir las fotografías, el video, el índice, navegar por tramos y compartir el enlace por WhatsApp.

### Vista previa de WhatsApp
